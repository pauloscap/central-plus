Hospedando Streamings
📡 Como hospedar um streaming na aba Apps:

Edite data/apps.json e adicione seu streaming assim:
{ "nome": "Meu Canal Belém", "webUrl": "https://seu-stream.com/live.m3u8", "type": "hls", // ou "iframe" para sites "host": "hospedado", // faz abrir no player interno da CENTRAL+ "cor": "#00a859", "letter": "MB", "categoria": "Ao Vivo Pará" }
Tipos:
• type: "hls" = link .m3u8 direto (seu servidor, IPTV legal) → abre com hls.js
• type: "iframe" = site web (seu player web, YouTube, etc) → abre embedado
• host: "hospedado" = abre dentro da CENTRAL+ em /player/?url=...
• host: "externo" = abre fora (Netflix, Disney+ precisam login externo)
